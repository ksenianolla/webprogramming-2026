# PigeonExpress интерактивная версия


- Приложение: https://ksenianolla.github.io/webprogramming-2026/hw2-pigeon-express/
- Макеты в Figma: https://www.figma.com/design/fbfnzs2LCKKWPWP3NoyUkq/PigeonExpress-ucd?node-id=59-5&t=OwGBW2Xgq1tdeJ1I-1

## 
`js/data.js` - Каталог птиц, классы доставки, начальные данные 
 `js/storage.js` - Чтение и запись `localStorage` / `sessionStorage` 
`js/store.js` - Состояние приложения: профиль, адреса, корзина, заказ 
`js/dom.js` - Создание DOM-элементов 
`js/format.js` - Форматирование цены и времени 
`js/components/`- Карточка птицы, диалог, адресная книга 
`js/pages/` - Скрипт для каждой страницы
