# PigeonExpress + API

React-приложение из четвёртого задания, подключённое к двум публичным API из списка [public-apis](https://github.com/public-apis/public-apis).

- Приложение: https://ksenianolla.github.io/webprogramming-2026/hw5-pigeon-express/dist/
- Макеты в Figma: https://www.figma.com/design/fbfnzs2LCKKWPWP3NoyUkq/PigeonExpress-ucd?node-id=59-5&t=OwGBW2Xgq1tdeJ1I-1

## Какие API используются

| Запрос | API | Где в коде | Что происходит на странице |
| --- | --- | --- | --- |
| `GET` | [Open-Meteo](https://open-meteo.com/) — погода | `src/api/weather.js` → `fetchFlyingWeather` | В корзине показывается погода в Санкт-Петербурге. Ветер и осадки добавляют минуты к времени доставки, это время видно в корзине, на странице оплаты и в статусе заказа |
| `POST` | [JSONPlaceholder](https://jsonplaceholder.typicode.com/) — заказы | `src/api/orders.js` → `sendOrder` | По кнопке **pay** заказ отправляется на сервер. Номер, который вернул сервер, показывается в статусе заказа |

JSONPlaceholder — учебный сервер: он отвечает так, как будто сохранил заказ, но на самом деле ничего не хранит, поэтому номер заказа всегда `#101`.

## Ошибки

| Ситуация | Что видит пользователь |
| --- | --- |
| Погода загружается | «checking the sky…» |
| Не удалось получить погоду | «no weather data», причина ошибки и кнопка **try again**. Время доставки считается без погоды |
| Нет интернета | Сообщение, что нет подключения |
| Сервер отвечает дольше 10 секунд | Сообщение, что сервер не отвечает |
| Сервер вернул ошибку (например, 500) | Сообщение с кодом ошибки |
| Сервер прислал неожиданный ответ | Сообщение об этом |
| Заказ отправляется | Кнопка меняется на **paying…** и не нажимается повторно |
| Заказ не отправился | Остаёмся в корзине с сообщением об ошибке, можно нажать **pay** ещё раз |

## Структура

| Папка | Что внутри |
| --- | --- |
| `src/api/` | `http.js` — общая функция запроса (таймаут, ошибки), `weather.js` — GET погоды, `orders.js` — POST заказа |
| `src/hooks/` | `useFlyingWeather` — загрузка погоды, `useOrderSubmission` — отправка заказа, остальные хуки из прошлого задания |
| `src/components/FlyingWeather/` | Блок с погодой в корзине |
| `src/lib/flyingWeather.js` | Описание погоды и расчёт задержки |

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, результат в папке `dist/`.
